# Исправления по аудиту

## Обязательная настройка перед запуском

1. Задайте `APP_USERNAME`, `APP_PASSWORD`, `SESSION_SECRET` (не менее 32 символов) и `DATABASE_URL`.
2. Перед публикацией выполните `pnpm db:migrate`.
3. Затем выполните `pnpm check` и публикуйте приложение.

## Что исправлено

- Персональная сессия теперь подписана HMAC, имеет срок действия и привязана к логину; добавлено ограничение попыток входа.
- При выходе браузеру отправляется команда удалить локальное хранилище и кэш.
- Приватные API и страница входа больше не кэшируются service worker.
- Разрешена только одна активная тренировка во всей базе.
- Сервер проверяет принадлежность подхода активной сессии; проверки добавлены и в offline sync.
- Завершение и отмена тренировки переведены на транзакции.
- Runtime ALTER/CREATE удалены. Добавлена версионированная SQL-миграция и команда `pnpm db:migrate`.
- JSON-экспорт ограничен тренировочными таблицами и больше не экспортирует push-подписки, журнал и VAPID-ключи.
- Добавлено проверяемое транзакционное восстановление JSON с подтверждением.
- Board press при AMRAP-пересчёте получает фактический свежий e1RM, а не восстановленное значение TM / 0,9.
- Мини-тейпер автоматически убирает изоляцию в циклах 4 и 8.
- CI дополнен отдельной проверкой типов.

## Проверка в этой поставке

- `npm test`: 23/23 теста пройдены.
- `npm run lint`: пройден.
- Production build и визуальный smoke-test требуют установки зависимостей. В изолированной среде проверки доступ к npm registry отсутствовал, поэтому их должен выполнить CI командой `pnpm check`.
